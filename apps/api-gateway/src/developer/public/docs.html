Để dùng API có quyền: chọn Identity → POST /auth/login → lấy accessToken → bấm Authorize và dán token (không thêm “Bearer”). Token chỉ giữ trong bộ nhớ trang; backend vẫn kiểm tra role và tenant.

Service này hiện mới có scaffold. Bạn có thể đọc contract; nút gọi thử được tắt đến khi API nghiệp vụ được triển khai.
